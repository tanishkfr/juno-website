A little help
getting started.

A home for your work. A few things to know before you begin.

Windows and installation

Juno’s beta is intended for Windows 11 x64. Get an installer only from the official published release linked on the Download page. The installer is unsigned, so verify its SHA-256 and source. Do not disable Windows security protections to install Juno.

Connect a model provider

Open Juno’s provider settings and choose a supported account sign-in or API-key connection. Availability, costs and usage limits belong to the provider you select. A chat connection may not authenticate every external Code worker; follow the setup shown in the app.

Code and Mission

Choose a project before working with its files. Code can inspect a project or perform an authorized change. Mission handles bounded tasks through planning, execution and verification where supported. Review approval requests and recorded results rather than assuming an answer means a task succeeded.

Updates and backups

Beta updates are manual. Read the published notes and known issues before installing. Back up your local work first. The website’s release history is separate from the app’s signed update-announcement feed.

When something goes wrong

Check your connection, provider quota and selected model. For a failed task, read the error and review the requested permissions before retrying. Avoid repeatedly authorizing an operation you don’t understand.

Talk to a person

Email madebytanishk@gmail.com with your Juno version, Windows version, what you expected and what happened. Review logs or screenshots for personal information before sharing them. Never send API keys or credentials.
