Before attaching anything

Remove prompts, code, API keys, credentials, personal conversations and other sensitive information from screenshots or logs. Share only what’s needed to explain the issue.

Before you write.

For issues specific to a version, check its published release notes. A few things apply across Juno’s beta:

Windows warns about an unknown publisher

The beta installer is unsigned. Verify the official source and SHA-256 on the Download page. Don’t disable security protections; managed PCs may need administrator approval.

A provider or model isn’t responding

Check the selected provider, authentication, network connection and quota in Juno’s settings. Provider access and charges depend on your connection. An external Code worker may require its own supported authentication.

A task is waiting for approval

Read the operation and its target before approving. You can deny a request you don’t understand. A model response is not proof that work completed; inspect the recorded result and verification evidence.

I can’t find the latest beta

Only published GitHub releases appear on the website. Drafts remain unavailable until publication. Updates are manual; Juno doesn’t automatically download or run an installer.

If you need to uninstall.

First save your work and keep a backup of any local data you need. Quit Juno, then open Windows Settings → Apps → Installed apps, find Juno and choose Uninstall. Read the installer’s prompts before confirming any data removal.

For help locating or preserving your data, contact support before deleting folders manually.

Understand what you’re sharing.

Local-first storage doesn’t mean external models run offline. Your selected provider receives the prompts and context needed for its calls. Read Privacy & permissions for the practical boundaries.
