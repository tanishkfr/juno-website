Remove the app.
Keep the choice.

Uninstalling Juno and intentionally deleting your local work are different actions.

Remove the application

  1. Save your work and back up anything you need.
  2. Quit Juno completely, including its tray process if it is still running.
  3. Open Windows Settings → Apps → Installed apps → Juno → Uninstall.
  4. Review the uninstaller’s prompts before confirming.

The public Windows installer guidance says the program is removed while local conversations, settings and credentials are kept by default. Removing Juno does not itself request permanent erasure of your workspace.

If you also want to remove local data

This is a separate, permanent decision. First identify the exact Juno data folders and any custom project locations you use. Confirm what they contain and keep a safe backup before deleting anything. A raw profile can contain credentials: protect it and never attach it to a support email.

Juno’s documented default profile locations are %APPDATA%\Juno and %USERPROFILE%\.juno. Custom configurations may differ. Do not delete a whole user profile, project directory or parent folder. No deletion command is provided here.

Prefer the explicit reset or removal controls shown by your installed version, where available. If you are unsure which data belongs to Juno or what will be lost, ask support before removing it. The website never deletes data on your PC.

External providers and projects

Uninstalling the app does not cancel provider subscriptions or erase external project folders. Manage provider access in the provider’s own account settings, and review any saved credentials before sharing a machine.
