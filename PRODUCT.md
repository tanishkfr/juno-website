# Juno website

## Platform
Web. Existing Vite/TypeScript site hosted on Vercel.

## Product truth
From the owner’s 15 November 2026 master brief: a local-first Windows desktop AI workspace for conversations, Code and longer-running bounded work. Six original companions and their identities remain. Local-first does not imply offline model execution.

## Website scope
Product storytelling, published GitHub release history, download guidance, Help and Privacy. The public distribution source is tanishkfr/juno-beta. Drafts are never download candidates. v0.5 remains a draft during development; preview fixtures must be explicit and non-downloadable. No desktop edits, installer rebuilds, release modifications, production deployment or release publication.

## Audience and success
People considering Juno on Windows should understand what it does, inspect genuine UI, find an eligible published installer and understand provider setup and permissions.

## Confirmed identity
Existing palette, pixel atmosphere, scroll color progression, giant Juno lettering and six companions. No literal sun/moon. Aria is a craft reference, not a rebrand.
