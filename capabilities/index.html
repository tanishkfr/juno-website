Preview is a boundary, not a promise.

Code and Mission are demonstrated using the current v0.5 renderer. Until a v0.5 release is published, that presentation is a preview rather than an available installer. Once published, it remains beta software: check that version’s notes and approved limitations.

Provider-dependent features are not automatically experimental. They need the relevant connection, authentication and tools. A screenshot does not establish that every provider or execution path is supported.

Check version-specific known issues.

What’s planned?

There is no public feature schedule promised on this page. Planned work is not presented as something you can download today. Published release notes are the record of what shipped.

Follow published updates or share a suggestion.
