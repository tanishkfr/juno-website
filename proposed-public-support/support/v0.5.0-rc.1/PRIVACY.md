# Privacy and permissions — Juno v0.5.0-rc.1

PROPOSED PUBLIC COPY — owner/release approval is required before publication.

## Local storage and connected providers

Juno stores workspace records locally. External model calls send prompts and the necessary context to the provider you select, under that provider’s policies. Local-first is not a claim that every model runs offline or that no data leaves your device.

## Permission controls

Review tool operations, file targets and access requests before authorizing them. Connected tools and websites may receive the information needed for an authorized task. An answer is not independent verification of a successful action.

## Reports and attachments

Review any diagnostics, logs or screenshots before sharing. Remove credentials, personal conversations, prompts, private code and identifying file paths that are not needed to explain the problem. Contact madebytanishk@gmail.com for support.

## Data retention

Removing the application does not itself request permanent erasure of the local workspace. Intentional data deletion is a separate permanent action; back up what you need, verify the exact scope, and ask for help before deleting folders you do not understand.
