# Installing Juno v0.5.0-rc.1

PROPOSED PUBLIC COPY — owner/release approval is required before this file is added to the distribution repository.

## Windows and downloads

Use Windows 11 x64. Download only the installer linked from the published GitHub release. Do not use a draft asset or an unpublished candidate. Read that release’s installation notes and compare the file’s SHA-256 with the published value. The installer is unsigned; do not disable Windows security protections.

## Provider setup

Connect a supported provider using the setup shown in Juno. External models need your own account, network access and quota. Code workers may need separate supported authentication; follow the setup in the qualified release. Model availability and charges are controlled by your provider.

## Updating

Updates are manual. Back up your work and quit Juno completely before installing a published update. Keep a safe pre-upgrade backup. Do not assume older Juno versions can open data upgraded by a newer release.

## Uninstalling

Open Windows Settings → Apps → Installed apps → Juno → Uninstall. Application removal and permanent data deletion are separate decisions. The public Windows guidance preserves local data by default. Keep a backup before any intentional reset or data removal, and verify the exact locations for your installation. No destructive filesystem command is required or provided here.
