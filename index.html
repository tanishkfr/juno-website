08Your control

Your desktop.
Your decisions.

Juno is local-first. Your workspace lives on your computer, and you choose the model providers and tools it connects to.

Connected AI providers and services may process the information you send them. Local-first doesn’t mean every model runs offline.

A workspace on your machine
Keep your conversations and working context in your local Juno installation.
Providers you choose
Configure the model provider for the work. Availability and usage depend on that provider.
Permission with a purpose
Set each bot’s tools and access. Keep approval-sensitive actions under your control.

09The private beta

Before you request access.

Windows requirements, provider setup and how invitations work.

Windows 11, 64-bit
This beta is for Windows 11 x64. The installer is currently unsigned, so Windows SmartScreen may show a warning.
A provider connection
Connect a supported provider in Juno with an account sign-in or an API key. Model access, usage limits and any provider charges depend on the connection you choose.
Access by invitation
Invited testers receive access to a private GitHub prerelease with the Windows build. Include your GitHub username in your request if you have one. Expect bugs and unfinished features.
